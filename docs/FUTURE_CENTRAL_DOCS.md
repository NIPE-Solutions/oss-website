# Future centralized documentation

Centralized documentation aggregation is not implemented in this release.
Individual project documentation remains the source of truth, and this site
only links to it.

If future needs justify aggregation, prefer a build-time process that imports
explicitly approved, versioned project documentation into a reviewable site
artifact. Preserve attribution, source URLs, release/version identity, and
clear ownership; do not fetch or transform external documentation per visitor.

Any proposal must define freshness rules, failure behavior, licensing,
accessibility, search scope, and owner review before implementation. It is out
of scope for the current release.
